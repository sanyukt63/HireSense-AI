# AI Model Evaluation

AI scoring should be evaluated separately from the surrounding recruitment workflow.

## Evaluation dimensions

- Precision and recall for classification tasks
- Extraction accuracy for resume fields
- Ranking quality for candidate-job matching
- Robustness to different resume formats
- Consistency across repeated evaluations
- Explainability of score contributions

## Evaluation principle

Do not treat a single aggregate score as sufficient evidence of model quality. Keep representative test data, document evaluation assumptions, and compare changes against a known baseline.

Recruiter review remains part of the decision process.
