# HireSense-AI Setup Checklist

Use this checklist when preparing a fresh development environment.

## Setup

1. Clone the repository.
2. Install the dependencies required by the project.
3. Configure environment variables from the project's existing examples or documentation.
4. Start the application using the repository's normal development command.
5. Verify the main user flow before making feature changes.

## Before committing

- Confirm the application starts successfully.
- Keep secrets and local environment files out of version control.
- Test the area affected by the change.
- Update documentation when setup requirements change.
