# AI Screening Bias Review Checklist

- Define job-related criteria before evaluating candidates.
- Check whether proxy variables may influence ranking.
- Compare performance across appropriate evaluation slices where lawful and feasible.
- Review false positives and false negatives.
- Keep score explanations available for human review.
- Document limitations and corrective actions.

A checklist does not prove a system is unbiased; ongoing evaluation is required.
